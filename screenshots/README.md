
# Lab Screenshots

This directory contains visual evidence of the HomeLab infrastructure and services deployed in this project.

The screenshots demonstrate practical experience with virtualization, container management, and security monitoring.

## Evidence

### 1. Docker Compose — Container Status

**File:** `docker-compose-status.png`

Shows the status of the Wazuh services managed through Docker Compose, including the Manager, Indexer, and Dashboard containers.

**Skills demonstrated:**
- Container lifecycle management
- Docker Compose administration
- Service status verification
- Infrastructure troubleshooting

### 2. Wazuh Dashboard

**File:** `wazuh-dashboard.png`

Shows the Wazuh web interface used for centralized security monitoring and event analysis.

**Skills demonstrated:**
- Security monitoring
- SIEM/XDR platform administration
- Security event visibility

### 3. Proxmox VE — Virtualization Overview

**File:** `proxmox-overview.png`

Shows the virtualized lab environment managed through Proxmox VE.

**Skills demonstrated:**
- Virtual machine management
- Infrastructure virtualization
- Resource and service organization

## Security and Privacy

All screenshots must be reviewed before publication.

- Credentials, tokens, private keys, and other secrets must never be exposed.
- Personal information and sensitive network details should be removed or obscured.
- Screenshots must represent the actual lab environment.

Only screenshots that have been captured and verified should be listed as available evidence.
